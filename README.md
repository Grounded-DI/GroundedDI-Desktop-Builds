## D.I. Principles

The public evidence is organized around
simple controls:

- preserve the source record;
- keep missing facts unresolved;
- separate analysis from prediction;
- show the current decision state;
- preserve the human review boundary; and
- make audit and replay inspectable.

## Scope and limits

This screen evidence uses a synthetic
fixture.

It is not live legal validation.

It is not a filing certification.

It does not guarantee an outcome.

It does not replace attorney review.

A screen capture shows the interface state
that was preserved. It does not, by itself,
prove production deployment or universal
performance.

## Repository role

This repository is the public desktop
build and evidence record for Grounded DI
local-first applications.

The surrounding files include implementation
records, audit and replay artifacts, build
materials, and visual work products.
